# Setup reports (historical)

Reports written during the initial data-forensics phase, before any modeling. They describe the
dataset as measured then and refer to the original working layout (`workspace/...`), which was later
reorganized into `src/`, `scripts/` and `data_work/`. Absolute local paths are replaced by
placeholders (`<project root>`, `<downloads>`). Raw outputs of the profiling scripts are in
`eda_outputs/`; the current profiling script is `scripts/analysis/data_profile.py`.
